                                        Usage & estimated cost

                                        Token counts are estimated (~4 chars/token), not exact. Cost is estimated for known hosted models only; Ollama/local models always cost $0. Not a substitute for your provider's own billing page.

                                        Ollama

                                        This machine

                                        Detected once when this tab is opened. VRAM detection needs `nvidia-smi`; without it, sizing falls back to system RAM (CPU/unified-memory inference).

                                        Suggested Ollama models

                                          Local image generation (ComfyUI)

                                          No API key - ComfyUI is a plain local server, same trust model as Ollama. Content is entirely up to whatever checkpoint you load; nothing here filters it.

                                            Pull a checkpoint

                                            Generic download by URL into your checkpoints folder above - works for any checkpoint file (Hugging Face, Civitai, anywhere); nothing here curates or suggests specific ones.

                                            Local speech generation (Piper)

                                            No API key - runs as a local process, not a server.

                                            Pull a voice

                                            Downloads from Piper's official voice repository (Hugging Face, rhasspy/piper-voices) into the folder above - e.g. name "en_US-lessac", quality "medium".

                                            Video generation (custom ComfyUI workflows)

                                            No built-in default - export a working workflow from ComfyUI's own UI as JSON, tell starfire which node/input holds the prompt text, and save it here. Runs against the ComfyUI server configured above.

                                              Backup

                                              Downloads a zip of the whole data/ directory - endpoints, encrypted keys, memory, documents, notes, chat sessions, everything.

                                              Restore

                                              ⚠️ Overwrites your current data with the contents of the zip. This cannot be undone - back up first if you're unsure.

                                              Add an account

                                              Each account has its own chats, memory, knowledge, notes, automations, email and prompts. Connections, MCP servers and local generation are shared and managed by admins.
